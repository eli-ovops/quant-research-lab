# 低延迟状态决策驱动的交易策略（当前方案）

2026-10-06 用户纠偏：共同特性是快速作出决策，目标是围绕短暂有效的交易机会构建策略。撤销下方旧设计中“两个模型分工串联”及以长文本公告解读为第一优先的安排。下方保留为历史设计记录，不再指导本轮执行。

## 当前核心假设

紧凑的实时状态输入，加上快速的有限动作输出，可能使复杂的条件判断在机会消失前完成。Jev/Decisions API 分别实现同一纸面决策接口，单次决策只用一个提供方，不串联两个云端模型。两者均未获得本机实际低延迟与交易效果验证，Decisions API 的可调用契约和权限仍 UNKNOWN。

“快速”需同时满足决策质量与整条链路延迟。API吞吐量、模型自述置信度、相对大型LLM的速度，均不直接证明费后可交易优势；固定代码与轻量数值模型也必须作为基线。

## 三种拟测试机制（均为假设）

1. **盘口短时失衡**：买卖盘被消耗或撤走后，判断短时延续、反转或不参与。输入包含有序盘口变化、主动成交方向与规模、价差、波动、已有价格反应。不能仅凭挂单量宣称真实购买意图或收益优势。
2. **成交冲击后的延续/回补**：较大主动成交后，快速区分订单流仍持续与流动性恢复。需要真实逐笔成交及盘口，只有K线、报价更新或OI代理时不能声称强平订单流已被观察。
3. **关联资产短时信息传导**：预先固定资产与方向关系，快速判断领先端变化后跟随端是否尚有费后空间。要与跟随资产自身动量及共同冲击对照，接收先后不等于真实先动；此前跨所事件研究不能直接作为此机制盈利证明。

先从一种机制完成最小验证，不同步开三条完整开发线，也不承诺这些机会一定存在。秒至几十秒是待测的研究尺度，不是已测得的机会寿命或API响应速度。

## 实时架构

公开有序行情/成交 → 本地增量特征与触发器 → 一次紧凑状态决策 → 确定性风险与新鲜度检查 → 纸面执行 → 出口与账务。

触发器避免每tick付费调用。状态只包含当时可得的必要字段及时间戳；不输出长解释。动作按是否有持仓限定为等待、纸面多、纸面空、退出或保持。行情特征、订单尺寸、费用、超时与风险由代码计算。AI可以选择合法动作，不能提高仓位限额或跳过新鲜度检查。

必须分别记录交易所事件时间、接收时间、特征完成、请求发起、响应完成、风险复核与可执行报价。决策完成后只接受新报价；超时/过期/行情断序/状态已变则丢弃。持仓退出保护不依赖每次云端模型成功响应。

## 最小验收顺序

1. **延迟**：核实接口与成本授权后，固定输入规模和输出动作，分别测两个模型的整链路p50/p95/p99、失败率及限流/重试影响。未调用前不填毫秒成绩；纸面路径不能证明真实订单确认延迟。
2. **机会寿命**：用有序事件和决策后真实盘口，测不同人工延迟下的费后表现曲线，包括不交易、失效、极端滑点。区分事后诊断与实时可知寿命，不能用未来曲线为每笔选择最佳等待时间。
3. **增益**：同一输入和合法动作比较固定规则/轻量数值基线、较慢模型、Jev、真实Decisions API。同时比较准确性、费后损益和实际延迟；AI成本计入，不把吞吐上限当延迟，不把置信度当盈利概率。
4. **新数据验证**：冻结触发、输入、问题、版本、费用及退出后做新数据前向纸面验证。未知排队/部分成交/实际手续费或执行路径不得填成验证成功。

可利用机会窗口必须覆盖实测行情接收至执行报价的完整耗时与缓冲。先测整链路分布，不把各环节单独p95直接相加当作整链路p95。若成本后没有机会，或延迟已经耗尽机会，该配置不进入盈利验证。

## 三条路线

### 1. 官方公告事件与预期变化（第一优先）

假设：对新增、确定且经济影响明确的信息作出更准确的分类，可改善固定事件候选的费后表现。公开消息不保证有滞后可赚，需要实际检验。

Jev 任务：判断公告是否包含相对已知记录的新事实；决定、提案或传闻的状态；涉及的具体实体；供给/需求/现金流机制；作用期限；证据是否不足。事实已公布时间、第一次采集时间、实体映射由代码或原来源提供，不能让模型凭记忆补齐。

拟议 Decisions 任务：读取上述特征和当前候选的已观测价格反应、价差、深度、成本及纸面持仓，从预定义合法动作中选择忽略、等待、纸面多、纸面空或退出。合法尺寸和风险由确定性代码先计算，不由模型自行扩大。

事件范围先选一种并预登记，例如官方供给变更公告；不能将所有公告混为同一方向，也不能因模型称利好就立即买入。历史预期、公告修订和第一次可获取时间缺失时，不能声称交易了事前未知的消息。

### 2. 同一事件下的关联资产选择

假设：同一事件对多个资产的经济暴露不同，语义特征可改善资产选择。Jev 评估直接/间接关联、影响机制及证据；拟议 Decisions 在固定候选集中选资产/方向/不参与。没有验证的事件—资产映射不得事后用收益补贴标签。

如采用多空相对价值，必须新增完整双腿资金、保证金、基差、对冲比例、资金费与失败执行账本。不能把两个独立账户相加，不能将相对价值自动称为无风险套利。因此本路线晚于单资产事件实验。

### 3. 信息状态驱动的策略选择

假设：信息与行情状态能在事前区分固定策略的条件适用性。Jev 解析消息驱动、预期兑现及不确定性；拟议 Decisions 在少量冻结策略和现金间选择。趋势/反转/事件延续等候选必须先有完整定义与账本。

所有候选若在对应状态都缺乏费后优势，选择器不能被假定有能力修复。禁止用整段历史中各策略的赢家标签，直接让模型选择事后最优策略。

## 第一个最小实验

在接口和时间戳数据可核后，只启动路线1的一种事件类型。初始范围为公开信息、单资产条件纸面账本，每组独立500USDT；风险和持仓上限在收益前确定并冻结。无真实资金。

四个主组：固定规则基线；仅 Jev；仅真实 Decisions API；两者组合。另加按事件簇/方向/入场次数与持有时间匹配的随机筛选诊断。不能用少交易的总亏损下降直接证明选得更好。

必须保存：原公告及版本、可得/采集时间、输入快照、模型/提示版本、原始回答、请求开始及完成时间、允许动作、决策、决策完成之后的真实报价、成本与纸面账本。不能按模型处理前的旧价格模拟入场；未采到可执行报价就无效，不倒填。

先评价事实/实体/事件分类，再评价交易净损益；语义准确率不能替代收益。AI与数据费用、滑点、资金费或借贷、无交易、拒绝、失败及尾部损失均保留。每个模型独立贡献和组合贡献分别报告。

开发样本可用于提出和修改语义问题；最终问题、规则及检验窗口冻结后，使用新数据验证。现有已看过的8月/9月外汇不能充当这个实验的独立检验。未来新事件优先；历史文本还须考虑模型可能已知后续结果的污染。
