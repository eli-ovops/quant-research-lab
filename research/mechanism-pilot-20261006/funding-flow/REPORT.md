## 成熟规则与关键缺口

当前 [官方频率公告](https://www.okx.com/en-eu/help/okx-to-enable-automatic-updates-for-funding-fee-settlement-period) 发布并于 2026-04-14 UTC 生效，cap/floor 触发后逐级 8→4→2→1h，而不是旧规则直接变 1h。自动恢复需在默认时钟上检查此前连续 12h 条件；个别合约可停用自动调整，不能只由当前配置倒推历史。

[官方资金费说明](https://www.okx.com/en-sg/help/perps-funding-fee-mechanism) 当前页面更新于 2026-08-27，计算含 `8/N` 归一因子；结算间隔缩短不等于资金费现金自动变成八倍。当前 BTC cap/floor ±37.5bps、ETH ±75bps 的快照与过去日期严格分开，历史 1bps 费率点不能冒充触 cap。当前快照的 nextFundingRate 为空；已有历史 realizedRate 不是预测档案。结算可能有秒级评估窗口，15m 开盘不能验证抢在结算前后的精确持仓状态。

[官方 API 文档](https://www.okx.com/docs-v5/en/) 公开 OI 历史端点已保存并实测；强平只确认现行公开 WebSocket 通道，其数据不代表全平台全部强平，没有在本轮启动长期订阅或补造过去标签。OI 收缩也可能来自普通平仓；价格压力更不能等同强平。盘口历史、买卖主动成交、排队优先级与真实成交缺失，限价触碰不能推断成交。
